# A reproducible evaluation before promises

Use only consenting adults or clearly synthetic subjects. Keep input and evaluation references separate. Start with 12 cases: front, three-quarter and profile crossed with standing/seated and simple/complex clothing. Keep framing, lighting, seed and iteration count recorded. Test at least two seeds per case, never report only the best output.

For every output, a human records `pass`, `fail` or `uncertain` for facial traits, body proportions, anatomy, garment fidelity and requested pose. A failed or uncertain identity/consent check blocks use in the intended published collection. Reviewers should see reference and output without knowing which backend made the output where practical. Record runtime, resolution, rejected outputs and hardware. Do not convert these judgments into a claimed biometric accuracy rate without an appropriate validated benchmark.

Report aggregate counts and representative failures, including unseen angles, hands, occlusion, unusual lighting and logo/text errors. Record whether clothing is imagined or represents a real product. Simulated clothes do not establish physical fit or size. Human consent and final review remain necessary.

Current project results: no real model generations or person-specific training performed. Test-double adapter passes are software correctness checks only, not image-quality evidence.
